# qPCR 상대 발현량 분석 앱

`streamlit run app.py`로 실행합니다. Python 3.10 이상에서 `pip install -r requirements.txt`를 먼저 실행하세요.

앱 형식 CSV 열은 `Sample,Condition,Gene,Replicate,Ct`입니다. QuantStudio에서 내보낸 `Results` 시트가 있는 `.xls` 또는 `.xlsx` 파일도 직접 올릴 수 있습니다. `Sample Setup`만 있는 CSV에는 Ct가 없으므로 분석할 수 없습니다. 기기 결과 파일을 올린 경우 시료명별 **실험 조건**과 **생물학적 시료 ID**를 화면에서 지정해야 합니다. 파일의 짧은 시료 코드만 보고 처리군을 추정하지 않습니다.

`Sample`은 생물학적 시료 ID이며 조건을 넘나들며 재사용할 수 없습니다. 한 시료에는 기준 유전자와 모든 표적 유전자의 측정이 있어야 합니다. 같은 시료·유전자에서 `Replicate`는 기술 반복 번호입니다. `Task=NTC`인 웰은 Ct가 검출되지 않으면 별도로 표시하고 계산에서 제외합니다. NTC에서 Ct가 검출되면 오류로 보고합니다. 일반 시료의 `Undetermined`는 웰을 기록한 뒤 자동 제외합니다. 숫자 Ct가 있으나 증폭 상태가 `Amp`가 아닌 웰은 오류로 보고합니다.

기술 반복 1회도 계산합니다. 이 경우 기술 반복 SD는 추정할 수 없으며 QC 표에 표시됩니다. SD 기준을 넘는 묶음을 포함하는 탐색적 분석은 화면 체크박스로 명시적으로 선택합니다. 결과는 QC 통과로 표기하지 않으며 원본 곡선 검토와 재측정 판단을 대체하지 않습니다.

`00X` 같은 시료 코드에서는 첫 숫자 0/1이 각각 Col-1/ost1, 가운데 숫자가 ABA 처리 코드, X/H가 각각 상온/고온을 뜻합니다. 저온군은 이 코드에 없습니다. ABA 단위는 파일에 없어 앱이 임의로 지정하지 않습니다. `00X`를 대조군으로 쓸 경우 화면에서 확인하세요. 서로 다른 시료명이 독립적인 생물학적 반복인 경우 동일 처리군으로 묶으려면 매핑 표의 실험 조건을 동일하게 지정합니다. 그래프는 유전자마다 상온/고온과 Col-1/ost1의 네 패널로 나누고 ABA 처리 코드를 가로축에 표시합니다.

앱에서 기준 유전자, 대조군, 기술 반복 SD 기준, 최소 기술 반복 수를 선택합니다. 기술 반복 Ct를 시료별로 평균낸 뒤 ΔCt = 표적 Ct − 기준 Ct, ΔΔCt = 시료 ΔCt − 대조군 평균 ΔCt, 상대 발현량 = 2^-ΔΔCt로 계산합니다. 조건별 값은 생물학적 시료의 상대 발현량 기하평균입니다.

이 앱은 NTC의 Ct 검출 여부만 확인합니다. 생물학적 시료 간 유의성 검정, 프라이머 효율, 기준 유전자 안정성, 용융곡선은 검증하지 않습니다. 그런 검증 없이 발현 변화의 통계적 유의성이나 생물학적 결론을 주장하지 마세요.

## 웹 배포

이 폴더의 `app.py`, `qpcr_analysis.py`, `requirements.txt`를 GitHub 저장소에 올린 뒤 Streamlit Community Cloud에서 `app.py`를 엔트리 파일로 지정하세요. Colab과 Localtunnel은 필요하지 않습니다. 공개 저장소를 쓰는 경우 실험 데이터나 비밀키를 저장소에 넣지 마세요.
